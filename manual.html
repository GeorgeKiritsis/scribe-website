Getting started

Open a folder as a project with Open Project (⌘O), start one from a template with New Project, or bring one in with Import from Overleaf or Git, which takes Overleaf's zip download or a git link. The paper is the .tex file with \documentclass in it, usually main.tex.

Press ⌘↵ to compile; the PDF appears on the right. If no LaTeX is installed, Scribe offers to install Tectonic, about 20 MB, which fetches the packages a paper needs the first time it compiles. With TeX Live installed, Scribe uses latexmk.

Double-click the PDF to jump to the line that made it, or press ⇧⌘J to go the other way. Select text in the PDF and press Show in source to find it in the LaTeX. Every command is in the menus, and in the command palette, ⇧⌘P.

Notebooks and the paper

A notebook is a Python file whose cells are separated by # %% lines, or a Jupyter .ipynb. A cell marked # %% [markdown] is text, written as comment lines. A cell marked # %% [figure: loss] makes a figure: whatever it plots is saved as figures/loss.pdf.

In the LaTeX, load \usepackage{scribe-figures}, which Scribe writes for you, and bring the figure in with \nbfig{loss}. A figure cell's Insert into paper button writes the whole figure environment. Run a cell with ⇧↵ and every notebook with ⇧⌘↵; a compile runs first the notebooks that changed since they last ran.

nbval(name, value, unit=, err=, sig=, raw=)
A number or text, read with \nbval{name}. With a unit, an uncertainty or a number of significant figures it is typeset by siunitx, so load \usepackage{siunitx}; the uncertainty is rounded to one significant figure (two if it starts with 1) and the value to the same place. raw=True writes LaTeX as it is.
nbtable(name, rows, header=)
A tabular, read with \nbtable{name}. Rows are lists, or a pandas DataFrame; a cell given as (value, uncertainty) is written value ± uncertainty, and columns of numbers are right-aligned.
nbmath(name, expr)
A formula, used inside maths as \nbmath{name}. SymPy expressions are converted; a string is taken to be LaTeX already.
\nbenv
How the notebooks last ran: Python and package versions, the seed, the git commit and the date. Useful in an appendix on reproducibility.

A value no notebook has exported prints as ?? in the PDF, and Check Before Submitting lists it.

Writing LaTeX

Completion knows your labels, citations, figures and notebook values. Errors come with a line in plain words and an underline at their place; turn on Compile on Save or Compile as You Type in the Build menu or in Settings.

Hover.
Rest the pointer on \ref to see the equation typeset, the figure drawn or the section's title; on \cite for the paper's title, authors and year; on \nbval for the value.
Writing checks.
Eleven slips are underlined as you type, each with a fix in its tooltip: a breakable space before \ref, a repeated word, straight quotes, $$ … $$, \bf and friends, ..., a space before \footnote, \label before \caption, unbalanced \left and \right, the space after “e.g.” and after a sentence ending in capitals. Each can be turned off in Settings.
Snippets.
Type fig, nbfig, tab, eq, ali, item, enum, sec, sub, frac, beg or thm, then Tab, and Tab again between the places to fill. Edit → Snippets adds your own, or imports a VS Code latex.json.
Equations.
Insert → Equation (⌥⌘E) opens the maths at the cursor in an editor where it is typed as it looks: / for a fraction, ^ and _, and a keyboard of symbols. It writes back LaTeX, keeping the environment and the \label.
Tables.
With the cursor in a tabular, Insert → Table opens it as a grid; elsewhere it inserts a new table. Paste a block from a spreadsheet into any cell.
Check Before Submitting.
In the Review menu: citations without an entry, references to missing labels, figures the text never mentions, missing images, stale notebook results, TODOs left in, and what arXiv would reject.
Export for Submission.
In the File menu: one zip of plain LaTeX a journal can compile, with every \input inlined and every notebook value written in.
History.
The clock in the sidebar lists earlier versions of the open file, kept at every save. Click one to see what changed since; Restore brings it back, and ⌘Z undoes that.
Git and the terminal.
The git panel commits, pushes and shows diffs; View → Toggle Terminal opens your own shell in the project folder.
Vim keys.
Turn them on in Settings, for the editor and notebook cells: normal, insert and visual modes, with :w, :q and :wq. Line numbers can be absolute, relative, or off.

TikZ

Put the cursor in a tikzpicture, in a .tex file or a .tikz file of its own, and press ⌥⌘K (Build → Preview TikZ). The picture is compiled alone, with the paper's preamble, and drawn in the side pane; it is drawn again after every edit, in about half a second. An error points at its line.

Moving.
Each point and node has a handle. Drag it and its coordinates change in the source; hold Shift to select several, and move, duplicate or delete them. Arrow keys nudge.
Drawing.
The tools draw lines, arrows, polylines, curves, rectangles, circles, ellipses, arcs, nodes, text and points. With the grid on, they snap to it. A line drawn from one node to another is written (a) -- (b), so it follows the nodes.
Styling.
The style bar sets the selection's colour, fill, line width and dash, arrow tips, node shape, font size and opacity. Double-click a node to change its text in place.
Writing.
Completion inside a picture offers TikZ options, the paper's colours and styles, node names and anchors. Insert → TikZ Picture starts one from a few shapes and adds the libraries it needs to the preamble.
Export.
As PDF, SVG or PNG, or Replace with the image: the picture becomes an \includegraphics and its TikZ moves to a .tikz file beside it. The Figures panel shows every picture in the paper as a thumbnail.

Everything the canvas does is an edit to the TikZ, so ⌘Z undoes it and the source is never out of step.

The assistant

Choose a provider in Settings → AI: Anthropic (Claude), OpenAI, Google Gemini, Ollama running on your computer, or any service that speaks OpenAI's API (OpenRouter, Groq, LM Studio). Paste your key; it is kept in the system keychain, never in the project. Until a provider is set, nothing is sent anywhere.

Ask about the paper.
View → Assistant (⌥⌘A) opens a chat that knows the outline, the section you are in and your bibliography keys. LaTeX in an answer can be inserted or put in place of the selection with one click. Below the box, the panel says what the next question will send.
Edit with AI.
Select some text and press ⌥⌘I: Improve Writing, Shorten, Fix Grammar and Spelling, More Formal, Simpler, Translate to English, Tidy the LaTeX, or Something Else, in your words. The change is shown word by word in the side pane; Accept puts it in, as one edit ⌘Z undoes.
Fixing errors.
A compile error in the Problems list has a button that asks for a fix, shown the same way before anything changes.
Suggestions as you type.
Turned on in Settings → AI: after a pause, the rest of the sentence appears in grey; Tab takes it, anything else lets it go.

Track changes and revisions

Review → Track Changes (⇧⌘E) marks what you type as \added[id=GK]{…} and what you delete as \deleted[id=GK]{…}, with the initials from Settings → Profile. These are the commands of the changes package, which Scribe adds to the preamble, so the marks show in colour in the PDF, in any editor and on Overleaf, and travel with git. The preamble itself is not tracked.

Comments.
Add Comment (⌥⌘M) on a selection highlights it and puts the comment in the PDF's margin; at the cursor it is a comment on its own.
Accepting and rejecting.
The Review panel lists every change and comment across the paper, by author, with Accept, Reject and Resolve, or all of a file at once. In the editor, ⌥⌘. goes to the next change and the Review menu accepts or rejects it. Show Changes in PDF switches between the marked-up paper and the paper as if every change were accepted.
Comparing with an earlier version.
Review → Compare with Earlier Version takes a git commit or a version Scribe kept on save, and latexdiff marks what changed in a PDF: deletions struck through in red, additions in blue. It needs latexdiff and latexpand, which come with TeX Live.
The response to the reviewers.
Response to Reviewers creates response.tex, one comment and reply per point. Select text in the marked-up PDF and Quote Selection for the Response puts it in the letter with its page.
Notes for later.
% TODO, % FIXME and \todo{…} are gathered in the Review panel too.

Looks

Settings → Appearance holds the look, which belongs to your computer rather than the project.

Themes.
Scribe Dark and Light, Gruvbox Dark, Solarized Dark and Light, Nord, Catppuccin Mocha and Latte, GitHub Dark and Light, Tokyo Night, or Match the System with one light and one dark. Any accent colour replaces the theme's.
Your own theme.
View → Theme → Edit Theme starts from the current one with every colour live; export it as a JSON file to share, or import someone else's.
Fonts.
JetBrains Mono, Fira Code, IBM Plex Mono, Iosevka, Source Code Pro, the system's, or any font you have installed; ligatures on or off, line height, and the size of the interface.
Dark PDF.
View → Theme → Dark PDF shows pages light on dark; pictures and included figures keep their own colours. The PDF file itself is unchanged.
Focus mode.
⌥⌘F: only the text, centred, with the line you are writing kept in the middle of the screen, and today's word count against a goal you can set. Esc leaves.

Notes

Notes are Markdown files: Notes → New Note, Today's Note (⌥⌘T) for a dated page, or Quick Note (⌥⌘N) to jot a line into notes/Inbox.md without leaving what you're doing. Maths, headings, checkboxes and images show as they will look; the line you are on shows its Markdown.

Links and tags.
[[Lecture 2]] links to another note, ⌘-click to follow; @kingma2015 is a citation; #exam is a tag. The Notes panel searches the text of every note, filters by tag, and shows which notes link to the open one.
Definitions and theorems.
A line starting Definition, Theorem, Lemma, Proposition, Corollary or Example (bold, or as a heading) is listed in the Notes panel, for revision.
Revision cards.
A line starting Q: with the answer on the next line starting A: is a card. Review asks the ones that are due; Again, Hard, Good and Easy (keys 1 to 4) decide when each comes back. Notes → Export Cards for Anki writes a file Anki imports.
Pictures, sketches and code.
Paste a screenshot or a photo with ⌘V; draw with Insert → Sketch (⌥⌘D), and double-click a sketch to draw on it again. Fenced code is highlighted in its language.
Into LaTeX.
Export Note as PDF typesets the note; Edit → Copy Note as LaTeX copies it, or the selection, ready to paste into a paper.

References and reading

The References panel lists the entries of your .bib files. Add one by its DOI or arXiv number with ⇧⌘C, or from Zotero: with Zotero 7 open and Allow other applications on this computer to communicate with Zotero turned on in its Advanced settings, \cite{ completes from your library and adds the entry it needs.

Each reference can have a PDF, papers/<key>.pdf, and a note, notes/<key>.md. Read the PDF in Scribe, select a sentence and press Highlight: the quote goes into the note under Highlights, with a link that opens the PDF at its page.
